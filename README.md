## Selected work

**[Pripremi.rs](https://pripremi.rs)** · Live
AI lesson-plan generator for Serbian teachers, with organic users and no paid marketing. Generation runs across OpenAI and Gemini with a quality gate and failover, and an in-house eval decides which model runs. Card payments through OTP Bank are built and in final testing.

**[Vir](https://github.com/djolex999/vir)** · [npm](https://www.npmjs.com/package/@djolex999/vir-cli) · 60+ releases
CLI and MCP server that turns Claude Code and Codex sessions into a searchable knowledge base for coding agents. Retrieval evals decide its defaults. Listed on awesome-claude-code. Companion [Obsidian plugin](https://github.com/djolex999/vir-obsidian) in the community directory.

**[serbeval](https://github.com/djolex999/serbeval)** · [Hugging Face](https://huggingface.co/datasets/djolex999/serbeval)
A small public benchmark of how well LLMs write Serbian: 351 items checked against Pravopis 2010, 30 models evaluated. v2 adds whole-passage corrections after the first version got too easy. Proposed for [lm-evaluation-harness](https://github.com/EleutherAI/lm-evaluation-harness/pull/4400) (open PR).

**[fokus](https://github.com/djolex999/fokus)** · 14 releases
Tauri / Rust desktop focus timer that hands focus back to the window you were in, natively on Windows and macOS.
